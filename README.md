# Meridian Estate — демо-сайт агентства недвижимости

Статический многостраничный сайт: 52 страницы, каталог из 21 объекта, админ-панель.

## Запуск локально

```bash
python -m http.server 8080 --directory site
```

Откройте http://localhost:8080. Двойной клик по index.html не подойдёт: ЧПУ-ссылки вида `/catalog/moskva/` работают только через веб-сервер.

## Публикация

Сайт задеплоен на Vercel: https://meridian-estate-six.vercel.app — каждый push в `main` публикуется автоматически. Альтернатива: перетащить папку `site` на https://app.netlify.com/drop.

## Что внутри

- `build.js` — генератор страниц (`node build.js`): шапка и подвал, метатеги, Open Graph, JSON-LD, ЧПУ, sitemap.xml, robots.txt. Домен задаётся константой `SITE`.
- `site/assets/js/data.js` — объекты, города, брокеры, контакты, ID счётчиков аналитики.
- `site/assets/js/core.js` — избранное, формы заявок, мессенджеры, аналитика (Яндекс Метрика и GA4 подключаются, если указать ID).
- `catalog.js` — фильтры, сортировка, вид «карта»; `object.js` — галерея, карта, ипотечный калькулятор, похожие объекты; `admin.js` — панель управления.
- Админка: `/admin/`, демо-доступ admin / meridian. Данные сохраняются в localStorage браузера.
